# Slidev Decks

## Start

- `pnpm install`
- `pnpm dev` (default deck)
- `pnpm dev:altcloud-apr-2026` (specific deck)

## Multi-Deck Structure

- `slides.md` is the default entrypoint and currently points to `decks/altcloud-april-2026.md`
- Add new deck files under `decks/`
- Run a deck directly with `pnpm slidev decks/<deck>.md`

## Build / Export

- `pnpm build`
- `pnpm export`
- `pnpm build:altcloud-apr-2026`
- `pnpm export:altcloud-apr-2026`
